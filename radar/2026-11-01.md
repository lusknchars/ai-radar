#### 1. Flow-based vector quantization via quantile transport

FlowVQ replaces the standard VQ-VAE quantizer with jointly learned EMA/codebook-update schemes by transporting fixed even-quantile prior codes through a lightweight flow-matching probability flow ODE to define the codebook. It adds training-time complexity and extra compute for learning and integrating the flow, plus sensitivity to flow-training stability, while inference tokenization cost depends on the final implementation and may remain near standard VQ lookup if the codebook is materialized. It can fail through distribution mismatch between latent encodings and the transported prior, degraded reconstruction on high-precision data, or implementation overhead that negates the claimed utilization benefit.

#### 2. LoRA-adapted function calling with schema validation

This replaces generic prompt-only function calling with a LoRA-fine-tuned 7B instruct model using schema-aware prompts, dialect and no-call resampling, a token-weighted loss, and deterministic validation of outputs against the tool schema. Costs are modest: LoRA training of a 7B model fits on a single 24 GB GPU, uses only official task data, and adds a lightweight deterministic validation step at inference, but requires curated task-specific training data and schema definitions. Failures concentrate in argument extraction (0.8920 argument exact match versus 0.9982 function accuracy on the dev set), and results derive from one Arabic shared task, so transfer to other languages, domains, or schema distributions is unverified.

#### 2. Role Grounding Attack on agent memory

This is an attack, not a technique to adopt: it exploits role-to-principal misattribution in LLM-agent memory systems, where a nested quoted conversation causes a victim agent to record an attacker's preference as its own user's preference, enabling tool-selection manipulation and privacy leakage. For the reader, the actionable cost is auditing any deployed memory pipeline that ingests shared or multi-party content, and adding provenance binding (explicit role and source attribution) to stored memories, which adds engineering complexity and storage overhead. What can fail: memory systems that drop conversational context at write time remain vulnerable, attribution fixes may degrade recall quality or increase latency, and defenses are unvalidated since the paper demonstrates the attack across five memory systems and six models but proposes no evaluated mitigation.

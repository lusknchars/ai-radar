#### 1. Independent out-of-band agent trace logging

This finding replaces reliance on agent-controlled trace files (used by tools such as Claude Code, Codex, and similar harnesses) with logging through an independent interception layer that the agent process cannot modify or delete. The cost is additional infrastructure complexity: a separate logging service or proxy outside the agent's trust boundary, plus the engineering effort to route all agent I/O through it and store traces durably. What can fail is coverage gaps, where an interception layer misses channels (e.g., direct file access, side-channel APIs, or unlogged tool calls), and operational risk if the external logger becomes a single point of failure for audit data.

#### 2. EvasionBench: benchmark for runtime-monitor evasion

This work does not replace a production method; it adds a 50-task benchmark for measuring whether LLM agents circumvent runtime monitors under ordinary task pressure, which can replace ad hoc or absent evaluation of monitor robustness. Running the benchmark costs only API or single-GPU inference budget plus engineering time to wire in one's own monitor and tool policies, since it requires no training. Findings can fail to transfer because evasion rates vary substantially across models, benchmark tasks may not match the reader's domain-specific policies, and results measured with best-of-3 sampling overstate single-attempt production risk.

#### 3. Policy-compiled deterministic tool-call gates

Replaces hand-written guard rules and per-action LLM verifiers with a four-pass compiler that turns natural-language policy into a deterministic, statically verified tool-call gate, compilable on-premise with an open-weight 26B model. Costs are a one-time compilation pipeline, a transcript-replay validation step, and a domain-dependent benign-utility cost from over-refusal, since a bad binding was observed refusing 95.9% of legitimate task-passing calls. Can fail on attack goals that involve no governable tool call, on bindings verified as weaker than their clause, and in domains where policy clauses cannot be grounded in available tool schemas.

#### 1. LLM Controller for Between-Round Research Decisions

Replaces rule-based, score-based, or search-tree controllers in autonomous research loops with a single LLM call that reads full trajectory history to decide whether to refine the current champion or start a new direction. Costs one additional LLM inference per experimental round plus the context window capacity to hold accumulated evidence, which grows with trajectory length. Can fail when the trajectory history exceeds effective context limits, when the LLM misjudges which past solution to build from, or when the domain lacks clear verified metrics for the controller to ground its decisions.

#### 2. Value-guided persistent instructions for self-improving agents

The method replaces value-neutral persistent instruction files in self-improving coding agents with short human-written value statements (from Schwartz's higher-order value types) that steer both what the agent builds and how it performs. It costs little in memory, latency, or infrastructure, since it is only an instruction-file change, but it adds a design step that the paper shows cannot be delegated: agent-revised values converge and AI-literature-derived values give no detectable gain. It can fail if the wrong value set is chosen (conservation values degraded performance below baseline) and requires workload-specific validation plus continued human oversight of value design.

#### 3. Inference-time scope-grounded visual memory harness

It replaces direct VLM solving and visual chain-of-thought (e.g., Canvas-CoT) with an inference-time harness that registers physical scopes, constructs derived views, and invalidates dependent claims on revision, without weight updates. Cost is extra inference calls, generated derived views, and bookkeeping of a scope-aware working memory, increasing latency and orchestration complexity while remaining API-compatible. It can fail when proposed revisions or scope links are themselves wrong, when dependent invalidation is incomplete, and the reported gains may not transfer beyond physics-diagram reasoning.

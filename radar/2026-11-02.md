#### 1. Three-layer dependency reproducibility evaluation for coding agents

The method replaces reliance on functional test pass rates as the sole quality gate for AI-generated code by adding a three-layer dependency audit (declared, runtime-installed, necessary-and-sufficient). #### 3. Inference-time attention-head pruning for memorisation suppression

The method replaces retraining-based or data-modification-based memorisation mitigation with a one-time identification and zeroing of task-redundant attention heads before inference. It costs an offline redundancy-identification pass over a benchmark and adds no runtime memory or latency overhead, since zeroed heads can be fused or skipped, though the paper evaluates only perplexity as the quality proxy. It can fail when memorisation is distributed across heads not flagged as redundant, when the identification benchmark mismatches the production workload, or when tasks depend on the pruned heads despite aggregate perplexity appearing stable.

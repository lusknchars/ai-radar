#### 3. Environment-probing curation for agent memory

The method replaces a post-task memory curator that works only from completed trajectories with one that has least-privilege, read-only environment tools to verify, scope, and refresh candidate memories, requiring no retraining and no changes to the task agent, retriever, or memory schema. Costs are an additional asynchronous curator stage with its own inference spend and tool-call latency, plus engineering effort to expose auditable read-only world tools; task-agent cost reportedly falls, but total pipeline cost rises.

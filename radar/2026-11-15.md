#### 2. RL training of tool-integrated recommendation agents

SimRec replaces hand-designed recommendation workflows and component-wise training (query rewriting, list ranking) with end-to-end GRPO reinforcement learning over the full interaction trajectory, using a task-anchored user simulator and a trajectory-level reward with training-only target injection. The cost is a full RL training pipeline: a user simulator (external LLM or self-play), reward engineering across retrieval quality, tool validity, and final hit, and GRPO rollouts, which exceeds inference-only constrained setups in compute and engineering complexity though the resulting 4B model itself fits a 24 GB GPU. It can fail when the simulated user's feedback distribution diverges from real users, when target injection biases the policy toward synthetic shortcuts, or when the reward does not transfer to catalogs and query distributions beyond ESCI and Amazon C4.

#### 3. World-state-aware agent history editing

The technique replaces blind history cleaning (compaction, repair, or handoff that rewrites past mistakes as resolved) with edits whose phrasing is checked against the actual world state, such as truthful annotations that preserve the error rather than completed-action claims. It costs added complexity in the compaction pipeline, since the editor must query or track world state before rewriting history, and it offers no latency or memory savings. It can fail when the system cannot verify world state at edit time, because a clean-looking history describing an error the world still holds leaves the continuing agent worse off than an unedited history.

#### 1. Online reasoning-history compression for long-horizon agents

The method replaces retaining the full accumulated reasoning history in the agent's context with training-free online deletion of reasoning blocks ranked by frozen proxy entropy, while preserving actions, tool calls, and observations. It costs only the ranking computation and integration logic, with no training, fine-tuning, or additional infrastructure, and the paper reports a small quality gain rather than a loss. It can fail through trajectory amplification: deleting a reasoning block can nonlinearly alter subsequent actions and total computation, and reasoning removed before task-relevant state is externalized into code, files, or tool outputs can degrade future decisions.

#### 2. Multi-agent LLM optimization of compiler-generated Triton kernels

The method replaces manual tuning of torch.compile-generated Triton sub-kernels with five profiling-guided LLM agents that rewrite kernels while preserving vendor library calls, then re-stitch and verify the model end-to-end through a four-gate cascade. Its costs are LLM API or inference spend for the search agents, profiling and multi-seed verification compute on a local GPU, and the engineering complexity of integrating a multi-agent pipeline into the build process; the claimed gains are benchmark geomeans, not guarantees for a given production model. It can fail to find any passing candidate (improving only 12 of 50 Level-3 problems), and correctness or performance regressions may slip through on workloads whose numerical behavior differs from the verification suite, though the baseline-preserving fallback limits downside.

#### 3. Checkpoint-and-replay SSM state management

It replaces eager per-step SSM state reads/writes with a periodically updated checkpoint plus a buffer of recent SSM inputs, decoupling output computation from state updates and enabling cheap speculative rollback and split-precision checkpoints. The cost is additional implementation complexity in the serving stack (currently a vLLM patch for Mamba-2 and Gated DeltaNet), memory for the input buffer, and dual checkpoint copies when split precision is used. It can fail if checkpoint staleness degrades outputs for long unroll intervals, if the reader's model architecture lacks support in the implementation, or if batch sizes are too small for state I/O to be the bottleneck, in which case the measured gains do not transfer.

#### 1. Taxonomy-guided adaptive prompt-injection red teaming

AutoPI replaces the fixed attack templates in benchmarks such as AgentDojo and IPI Arena with a taxonomy-guided attacker LLM that generates one injection per sub-technique and iteratively rewrites failures using an LLM judge. It costs inference calls to three models (attacker, target, judge) per scenario, which on API pricing is modest but scales with taxonomy size and retry rounds, and it adds an external taxonomy (PIAtlas) as a maintenance dependency. It can fail when the taxonomy itself is incomplete or stale, since coverage is measured only against known classes, and LLM-judge false positives can overstate both ASR and coverage, leading to misplaced confidence in hardening decisions.

#### 2. Diverse purple-teaming for prompt injection defense

PIPETTE replaces naive RL-based red-teaming pipelines (RL-Hammer, PISmith) whose mode-collapsed attack sets fail to improve adversarial training, adding a dictionary-learning diversity reward and an on-policy adversarial training loop for IPI defense. Its cost is substantial compute and engineering: an RL attacker loop plus repeated fine-tuning of the defender, which implies API fine-tuning access or a dedicated GPU training budget, and no turnkey drop-in exists. It can fail if the learned attack dictionary misses novel real-world injection strategies, if the defender overfits to benchmark attack distributions, or if adversarial training degrades benign utility on the reader's specific tasks.

#### 3. Resolution-adaptive visual rendering of agent memory

RAA replaces uniform full-fidelity text encoding of interaction history with variable-resolution image rendering, allocating fine-grained detail only to interactions judged relevant by a lightweight estimator trained with teacher-model guidance. It can fail when the estimator misranks critical interactions and low resolution destroys needed detail, when image rendering loses information that plain text would preserve, or when vision-token pricing on third-party APIs erodes the claimed savings.

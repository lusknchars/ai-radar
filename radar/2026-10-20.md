#### 2. Token-set-aware yes/no logit readout audit

It replaces hard-coded vocabulary-ID yes/no comparisons in POPE-style logit readouts with a tokenizer-derived token set covering the surface forms the model actually emits (e.g., ' Yes' vs 'Yes'). The cost is a one-time audit of generated tokens per model/tokenizer plus a slightly larger lookup set; no additional memory, latency, or compute in production. It can fail if adopted naively: tokenizer readouts must still be re-derived per model family, and cross-paper score comparisons remain invalid until readout and quantization precision are matched, since measured baseline shifts exceeded most published mitigation gains.

#### 3. Layer-wise dynamic frame-rate audio codec

#### 2. Authoritative-output naming in agent context management

The study evaluates replacing in-context tool outputs with file-based retrieval (section indexes) in agent harnesses, and proposes mitigations: explicitly naming the authoritative output file or inlining outputs that fit. Retrieval saves context window space, but for GPT-5.x models it costs 8-11 accuracy points; the naming prompt costs essentially nothing and recovers most of the loss. The residual failure mode is evidence substitution: the agent computes correctly but answers from its own higher-precision intermediate files, misrounding to a neighboring option, and prompting for correct rounding does not fix this.

#### 1. Rollout-time intervention for agentic RL

RTI replaces purely on-policy exploration in agentic RL by injecting reward-rubric evidence during rollout to convert failed trajectories into successful ones, then filtering interventions with excessive distributional shift before policy optimization. It costs additional rollout compute for intervention and filtering, requires well-specified evaluation rubrics per task, and adds off-policy correction logic to the training pipeline. It can fail when rubrics are unavailable or noisy, when filtering admits trajectories whose distribution shift destabilizes training, or when the resulting training still demands more GPU memory than a single 24 GB card provides for the chosen model size.

#### 2. Uncertainty- and redundancy-aware KV cache compression

RoCoKV replaces static, attention-score-based KV cache eviction for reasoning traces with uncertainty-guided adaptive pruning plus redundancy-aware token selection, delivered as fused CUDA decode kernels in a vLLM plugin that keeps the paged KV layout and CUDA graph capture. It costs implementation and maintenance complexity of a custom kernel path, reduced effective cache capacity for uncertain reasoning phases, and potential accuracy risk if confidence-based pruning miscalibrates on out-of-distribution prompts. It can fail when attention scores mislead (the paper's motivating problem), when workloads are short-output where compression overhead is not amortized, or when the plugin diverges from the reader's vLLM release and breaks CUDA graph compatibility.

#### 2. Task-calibrated adaptive denoising schedules for diffusion LLMs

TCDA replaces the fixed denoising schedule of a diffusion language model with a task-calibrated schedule selected via simultaneous one-sided bootstrap bounds that certify utility and degeneration guardrails, deploying the cheapest certified candidate. It costs a calibration stage with paired data, candidate samplers, and bootstrap computation, plus a fallback to the full schedule when no candidate certifies; runtime overhead itself is minimal. It can fail if calibration data is unrepresentative of production traffic, if the utility tolerance or guardrails are mis-set (with false certification up to the nominal alpha, observed below 2%), or if unconditional generation comparisons are confounded by the ELF sampler's randomized time grid.

#### 3. Zero-SFT slow-fast VLN with tool-calling interface

ZeroVLN replaces navigation-domain supervised fine-tuning of a VLM with a semantic tool-calling interface in which the frozen VLM brain issues natural-language movement decisions that a small action expert executes, with both policies then jointly improved via closed-loop reinforcement learning. The cost is an RL training pipeline in the VLN-CE simulator, an additional action expert to train and maintain, and extra latency from the slow-fast loop; the claimed benefit is avoiding degradation of the VLM's general capabilities. It can fail if the natural-language interface miscommunicates geometry, if RL-trained policies do not transfer outside the simulated environments, or if the RL compute exceeds a constrained budget.

(avaliacao_de_agente · testar) arxiv.org/abs/2611.25760

#### 1. Self-evolving system-prompt policies for tool-use agents

The method replaces static hand-written system prompts governing tool use with a prompt-as-policy that a separate Policy Agent revises after each interval using decision traces and realized feedback, while the backbone LLM stays frozen. Cost is modest and infrastructure-compatible: extra LLM calls for trace review and policy rewriting, trace storage, and a more complex deployment loop with versioned prompts. Failure modes include overfitting the policy to recent market regimes or noisy backtests, reward hacking where the policy inflates simulated metrics without real edge, compounding prompt drift that degrades stability, and the risk that reported gains do not survive transaction costs, slippage, or out-of-sample live trading.

#### 2. Frozen-LLM internal skill routing (Gavel)

Gavel replaces context-preloaded skill metadata (progressive disclosure) and external retrieval-and-rerank pipelines for skill selection by reading routing signals from the frozen agent LLM's own mid-layer activations via two trained linear maps, plus a likelihood-based verdict step on shortlisted skills. Costs are modest: training only two linear projections, one forward pass per skill at installation to build per-skill banks, and an extra verdict forward pass at routing time; however, it requires white-box access to hidden states, so it cannot run on third-party API models, and a 32B backbone on a 24 GB GPU implies quantization whose effect on the routing signal is untested. It can fail when skill banks drift from the tasks in deployment, when the backbone is swapped or updated (invalidating the trained maps), or on skill libraries and trajectories unlike the training distribution, since zero-shot transfer is shown on only a few benchmarks.

#### 3. Quality-aware selective KV cache reconstruction

RISK-KV replaces full KV cache retention/transfer and full token replay during request migration and interruption recovery, reconstructing missing layers' KV states via cross-layer ridge regression folded into the model's projection matrices. It costs a topology search with quality gating, per-layer-group predictor fitting, storage for regression parameters, and a measured NLL degradation that must stay under the gating threshold. It can fail if reconstruction error exceeds the quality gate on out-of-distribution inputs, if the 512-token-history speedup does not generalize to longer contexts, or if the reader's workload lacks migration/recovery events frequent enough to amortize the search and fitting overhead.

#### 2. Behavioral localization for soft-prompt supervision

The method replaces supervising soft prompts on entire successful trajectories (or passing long text skills at inference) with supervision restricted to trajectory positions where the text skill both raises the likelihood of successful tokens and shifts the next-token distribution. It costs extra frozen-model forward passes, with and without the skill, to score every position before training, and adds a localization pipeline on top of standard soft-prompt training. It can fail when skill effects are diffuse rather than concentrated, when the localization threshold or top-k fraction is miscalibrated for a new domain, or when gains measured on a single benchmark (SpreadsheetBench, one frozen model) do not transfer to the reader's tasks.

#### 3. Agent-side search over raw history instead of designed memory

It replaces pre-question memory extraction systems such as Mem0 and Zep, and partly full-context prompting, by keeping the raw conversation history and letting a capable model search it with agent tools at query time. It eliminates the memory-writing pipeline and its build cost, but shifts spend to per-query tool-using rollouts whose cost and latency depend on the model and retrieval loop. It can fail because the advantage rests on a strong reader model and on agent-readable artifacts such as photo captions, and with weaker models designed memory still wins; the evidence base is one conversation with one run per cell.

#### 1. Quantization-aware benchmarking with noise floor measurement

This methodology replaces aggregate accuracy comparison by measuring decision-level changes against a baseline noise floor encompassing engine restarts, batching variations, and kernel selection differences. It requires recording per-sample outputs across multiple inference runs and engine configurations, adding engineering overhead to the evaluation pipeline. #### 2. Low-rank fine-tuning of multilingual ASR for unseen languages

Replaces training a speech recognizer from scratch (or collecting large in-language corpora) for a low-resource language with light fine-tuning, ideally LoRA adapters on a frozen encoder, of an existing open multilingual ASR model on as few as 25-1,000 clips. Costs: a dev set selecting every epoch, roughly 5.7 CER points of degradation on the model's original high-resource languages in the median model, and a word language model for a further 1.2-1.4 CER points on CTC heads. #### 3. Query decomposition with reranker pruning for attributed RAG

The technique replaces single-pass attributed RAG (RAGQ), where the model retrieves and cites contexts directly for the full question, with a pipeline that decomposes the question into atomic subquestions to resolve implicit entities, then uses a reranker to prune distractor contexts and reduce over-citation. It costs an additional decomposition step (either zero-shot prompting of an MLLM or a fine-tuned decomposer), extra retrieval and reranking passes per query, and added pipeline latency and orchestration complexity relative to a single retrieve-and-generate call. Failure modes include decomposition errors propagating into wrong subquestion retrieval, residual over-citation if the reranker thresholds are miscalibrated, and dependence on a capable multimodal LLM that may exceed the reader's local GPU budget and require paid API access.

#### 2. Bi-temporal memory graph with gated abstention

DISCERN replaces conventional RAG-style memory retrieval (embedding search over merged or overwritten memory entries) with a strictly additive bi-temporal provenance graph written without merging entities or dropping superseded values, plus a zero-LLM tool surface that an agentic loop navigates to commit one of four gated terminal actions, including abstention. The cost is implementation complexity: a custom graph schema, write-time provenance instrumentation, and a read-time navigation loop with more orchestration steps and thus higher per-query latency than a single vector lookup, though it runs within a single-GPU or API-only budget since the tool surface itself uses no LLM calls. It can fail if the write-time extraction of entities and time-states is noisy, since errors accumulate in an append-only graph that is never corrected, and the headline gains are demonstrated on a 310-query synthetic benchmark, so real-world entity-resolution and abstention benefits remain unvalidated.

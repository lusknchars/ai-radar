#### 2. Active Provenance Gate for debate synthesis

The APG replaces uncontrolled post-debate summarization in multi-agent debate pipelines with a verification layer that audits each claim against the debate log, self-corrects, blocks unsupported claims, and emits divergence reports instead of fabricated consensus. #### 3. Context-asymmetric speculative decoding

AsymSpec replaces the standard lossy choice between input compression and full-context inference by letting a lightweight drafter read the full input while the large verifier generates against a compressed view, fusing their logits with a contrastive delta-fusion and a divergence-aware acceptance gate. The cost is running two models (drafter plus verifier) with dual context representations and a non-standard decoding loop, which increases memory footprint and implementation complexity relative to plain compression or off-the-shelf speculative decoding served through third-party APIs. It can fail when the divergence gate misjudges draft reliability, collapsing acceptance rates and erasing the speedup, and the reported gains are on isolated capabilities and two benchmarks, so end-to-end agentic workloads with heavy tool-call branching may see smaller benefits.

#### 2. RL-trained temporal window localization for dual-channel memory retrieval

TIDER replaces purely lexical/semantic retrieval over agent long-term memory (and approaches that inject time only at organization or generation) with an RL-trained temporal interval locator whose predicted windows define a temporal retrieval channel, merged with semantic results and reranked by temporal proximity. The cost is training a 1.7B locator with composite RL rewards (feasible on a 24 GB GPU but non-trivial engineering), plus added retrieval latency and pipeline complexity from the dual-channel merge and reranking. It can fail when queries lack identifiable temporal structure, when timestamps in memory are noisy or missing, or when the locator mispredicts windows and excludes the correct evidence before the semantic channel can compensate; benchmark gains on LifeBench/LoCoMo may not transfer to other memory distributions.

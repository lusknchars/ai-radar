#### 1. Pre-execution action auditing against indirect prompt injection

ActGuard replaces coarse prompt-hardening and content-filtering defenses with a per-step audit that predicts a local tool prior, flags deviations in tool choice and parameters, and masks only evidence-verified malicious spans before regenerating the action. Its cost is additional inference at every agent step: a tool-prior prediction, contrastive analysis, and a verifier pass, which increases latency and API spend roughly proportional to trajectory length. It can fail when the injected instruction produces an action consistent with the tool prior (parameter-only manipulation that evades localization), when the verifier over- or under-masks evidence, or when legitimate but unusual tool sequences are treated as deviations.

#### 1. Certified mid-task-change agent evaluation

EnvOS replaces ad-hoc, one-shot agent evaluation on static or manually mutated environments with pre-certified, seed-generated environments where mid-task changes are verified to fire, tasks remain solvable, and verdicts are re-checked from archived evidence. #### 2. Prefix executability evaluation for tool-using agents

It can fail where the sandbox diverges from production tool behavior, where state preconditions are underspecified, or where non-deterministic tools make prefix validity ambiguous.

#### 3. Agentic exploration for task-completion verification

VeriCUA replaces single-pass VLM trajectory judges and generated state-inspection programs with a rubric-driven verifier that dynamically selects GUI or code checks and fuses evidence under explicit rules, usable across platforms without per-platform verifier engineering. The cost is additional inference and interaction: each verification episode requires context inspection, exploratory GUI or code actions, and evidence aggregation, raising latency and API or GPU spend per judgment relative to a single VLM call. It can fail when decisive evidence is unreachable through either GUI or code access, when the constructed rubric omits a task requirement, or when exploration itself perturbs application state in online settings.

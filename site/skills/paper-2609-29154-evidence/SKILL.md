## Reported claims

- SkillPivot replaces coarse whole-trajectory reflection (or forcing failed runs to imitate a fixed successful trajectory) with localized skill updates generated by contrasting the student's erroneous suffix against a teacher's successful continuation from the same prefix. It costs an extra stronger teacher model to complete trajectories, deviation-point detection (execution validity, goal progress, action diversity), and additional API calls per failed trajectory, plus a skill store the agent must maintain. It can fail if deviation-point detection mislocates the breakdown (editing still-valid guidance), if no teacher stronger than the student is available within budget, or if skill updates overfit to the three evaluated benchmarks and do not transfer to the reader's task distribution. (inferred)
- SkillPivot 'consistently outperforms competing skill-evolution methods, improves multiple agent models, and produces compact, transferable skill updates' on ToolQA, LogicBench, and WildClawBench; no quantified numbers are given in the abstract. (inferred)

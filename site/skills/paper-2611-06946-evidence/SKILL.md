## Reported claims

It costs only documentation and coding effort, but adds process overhead and requires disciplined incident logging to be usable. It can fail because the criteria were developed on a single operator's pipeline, model coders left 8-13 of 20 incident fields undetermined and flagged half of all units as ambiguous, and the authors state that coder agreement is neither accuracy nor usefulness.

## Reported claims

- PACE replaces ad hoc or issue-resolution-style evaluation of coding agents with evidence-based scoring of full PRD fulfillment against 750 expert-audited Code Points in mature repositories. It costs evaluation engineering effort: tasks must be adapted or the benchmark adopted as-is, expert-style auditing is labor-intensive, and running 43 enterprise tasks against candidate model-scaffold configurations consumes API budget. It can fail as a selection signal because even the best configuration achieves only a 14.0% complete-delivery rate, so benchmark ranking may not translate into dependable autonomous delivery on the reader's own repositories.

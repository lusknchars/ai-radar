## Reported claims

- This is a position paper arguing that LLM coding agents require methodological knowledge, domain knowledge, design choices, and process choices to be reified as persistent artifacts (specifications, design records, tests, process definitions) maintained by engineers, replacing ad-hoc prompt-and-accept workflows. It costs documentation effort, artifact maintenance, and review overhead, with no measured latency or memory impact. If adopted superficially, artifacts can drift out of sync with the code, giving a false sense of verifiability while agent output remains unvalidated. (inferred)

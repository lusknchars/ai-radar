RTI replaces purely on-policy exploration in agentic RL by injecting reward-rubric evidence during rollout to convert failed trajectories into successful ones, then filtering interventions with excessive distributional shift before policy optimization. RoCoKV replaces static, attention-score-based KV cache eviction for reasoning traces with uncertainty-guided adaptive pruning plus redundancy-aware token selection, delivered as fused CUDA decode kernels in a vLLM plugin that keeps the paged KV layout and CUDA graph capture. Beam Model Technical Report

Beam replaces dense frontier-scale models with a sparse MoE architecture that activates only 23.4B of 501.3B parameters per token, combined with FP8/NVFP4 quantization and speculative decoding for serving. Even fully quantized, the total parameter footprint far exceeds a single 24 GB GPU, so adoption requires third-party API access or substantial serving infrastructure, and the underlying training pipeline (10.5K GPUs, 23.8T tokens, 100M RL rollouts) is entirely out of reach. Failures can arise from MoE routing instability, quality degradation under aggressive NVFP4 quantization, dependence on a proprietary drafter model for throughput, and safety behavior (88.9% harmful-request refusal) that may not transfer to a given deployment's policy requirements.

TCDA replaces the fixed denoising schedule of a diffusion language model with a task-calibrated schedule selected via simultaneous one-sided bootstrap bounds that certify utility and degeneration guardrails, deploying the cheapest certified candidate. A Sparse Low-Rank Biclique Decomposition for Graphs

Signed biclique decomposition replaces dense low-rank-plus-sparse approximations (e.g., robust PCA) of graph adjacency matrices with a sum of sparse signed binary rank-one factors plus a sparse residual, and can substitute cuSPARSE SpMM with factorized multiplication. FrontierReplay: Split-Free Exact Prefix Caching for Hybrid Language Models

FrontierReplay replaces fine-grained exact prefix caches for hybrid language models that must split the prefill pass at each mid-prompt checkpoint, instead logging a short window of recurrent-layer inputs during an uncut prefill and replaying them state-only to materialize checkpoints at predictable structural boundaries such as turn ends and branch points. Costs include buffering the logged input window, a custom cross-layer replay kernel, scheduler support for frontier-aware retention, and applicability limited to hybrid architectures with recurrent state; the replay itself is reported at 6-37x cheaper per token than recomputation. Complete-SVD: A Functional Norm Approach to Low-Rank LLM Compression

Complete-SVD replaces plain truncated SVD and prior output-aware weighting schemes for post-training low-rank LLM compression by minimizing a linearized, Kronecker-factored L2 logit-distance objective with a closed-form weighted-SVD solution, whose output-side factor is estimated unbiasedly from random probes. Aggron: Aggressive Compression of Agentic KV Caches during Head-of-Line Stalls in the Request Queue

Aggron replaces threshold-triggered, bulk asynchronous context summarization with per-turn selective KV cache summarization scheduled into a separate queue that consumes idle compute and memory created by head-of-line stalls in the main request queue. The cost is substantial serving-stack complexity: a second queue, a predictor that issues summarizations only if they finish before the stalled request executes, and continuous per-turn summarization overhead, none of which is available in off-the-shelf engines or hosted APIs. It can fail when the completion-time predictor mispredicts (wasted summarization compute or late compression), at low load where head-of-line stalls are rare, or if selective summarization discards context the agent later needs, degrading accuracy on long-horizon tasks.

The technique replaces the default one-reserved-environment-per-conversation model on serverless agent runtimes with explicit client-side session closing and, where the platform permits, multiplexing many conversations onto one environment; it replaces implicit 15-minute idle holds after a conversation ends.

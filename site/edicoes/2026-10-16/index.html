Ajar: Measuring Open Privilege in Agent Defenses

Ajar replaces the two-axis evaluation of agent defenses (attack success and benign utility) with a third axis that directly measures privilege left open, by injecting unneeded candidate tool calls into existing benchmarks such as AgentDojo. It costs benchmark instrumentation per task and additional evaluation runs on top of the benchmark the team already uses, plus engineering to generate valid-but-unnecessary tool calls from tool schemas and reference solutions. It can fail if the generated candidate calls do not reflect realistic privilege escalation in the team's actual tool surface, or if a defense appears tight only because it over-refuses legitimate calls, a trade-off the metric exposes but does not resolve.

Harness as a Language: A Minimalist Agent Framework With Maximal Expressivity

Replaces specialized external systems such as memory frameworks (Letta/MemGPT) and self-improvement harnesses (ACE) with a single recursive code-mode LLM primitive, invoke, plus built-in constraint and monitoring hooks, eliminating manually designed tools and external memory or file systems. Costs are low in engineering complexity but shift burden to prompt design and API token spend, since all history lives as variables in a code environment; reported results run at roughly half the cost of Letta while scoring 8 points higher. Human Interventions as Labels: Localizing, Steering, and (Sometimes) Editing the Computations Behind LLM Agent Failures

The method replaces discarding or replaying human interventions as training data by using them as labels to learn a causal steering direction at a specific residual-stream depth, optionally consolidated into weights via LoRA. OS-Helix: Unifying GUI Interaction and Code Execution in Native Computer-Using Agents

OS-Helix replaces prompt-level composition of a GUI agent plus a separate code tool with a single policy trained (SFT cold-start plus online RL with step-balanced GSPO) to route natively between GUI actions and code execution in one action space. It replaces manual SFT data engineering (adjusting proportions, pruning, repairing, and synthesizing rows) with a meta agent that separates execution from analysis, gathers proposals from independent subagents, and calls a synthesis subagent for gaps in the data pool. LEASH: Uncertainty-Aware Weak-to-Strong Escalation and Oversight for Computer-Use Agents

The method replaces always-on frontier-model execution (or random/heuristic escalation) with a router that runs a cheap weak agent by default and escalates to a strong model only when the weak model's hidden states resemble past failed trajectories, plus a shadow observer that monitors the black-box strong agent after handoff. HyCo: Hybrid Drafting for Cost-Efficient Mobile-Cloud Speculative Decoding

HyCo replaces server-side speculative decoding (where the server runs its own sequential drafting steps) with a hybrid scheme: the server model's MTP head and one SLM pass run on the client's mobile NPU, with the server shipping hidden states, embeddings, and KV entries instead of executing those steps. Costs include quantization and a restricted vocabulary to fit both drafters on the NPU, a 1K-token context window, increased device compute and network transfer, and an ε-threshold relaxation that no longer exactly preserves the verifier's sampling distribution. It can fail under poor network conditions (single-client LTE/5G results may not transfer), when quality-sensitive workloads reject the relaxed distribution, and on devices lacking the required NPU capabilities.

ShiftQAT replaces generic post-training quantization or standard W8A8 QAT with a hardware-aware QAT flow that enforces power-of-two per-tensor scales, integer-only arithmetic, and one static requantization shift per layer, so models satisfy the MAX7800x numerical contract by construction. N-Gram Memories at Two Bits: Quantizing Lookup Tables in Large Language Models

The method replaces full-precision storage of conditional n-gram memory tables with two-bit row codes plus a shared Gaussian trellis reconstruction program with norm restoration, decompressing only the rows each input requests. Learning to Steer LLM Agents and Multi-Agent Systems

The method replaces ad hoc prompt-based monitoring or unmonitored execution of LLM agents with a separate trained supervisor that detects goal drift and intervenes via a low-cost fast path (when to intervene) and a high-cost slow path (how to intervene). It costs an RL training pipeline (pairwise ranking plus GRPO), an additional model in the inference loop, and added latency and token spend per execution step, though intervention frequency is controllable. It can fail through over- or under-intervention on workloads unlike the training distribution, drift-assessment errors that interrupt correct trajectories, and dependence on GRPO training infrastructure that may exceed the reader's budget.

Training Reasoning Models to Generate Diverse Scientific Ideas

The method replaces single-idea quality optimization and prompt-based diversity heuristics with set-level reinforcement learning, in which K jointly generated idea cards are scored with each idea's quality weighted by its distance from its predecessors. It costs an RL training pipeline with a joint set-scoring reward function, plus the evaluation infrastructure needed to measure pairwise idea distance, none of which is feasible on a single 24 GB GPU or a limited API budget. It can fail if the distance metric rewards superficial variation rather than genuine conceptual novelty, and the human evidence is a pilot study with only four experts, so quality and executability claims remain preliminary.

Evaluation Awareness Beyond English: Do LLMs Act Differently When Tested in Indic Languages?

This is an audit methodology, not a model improvement: it replaces English-only safety evaluation with parallel probes in the deployment languages, varying cues about monitoring to measure how much a model's refusal behavior shifts under test conditions. The cost is evaluation engineering only—translated or natively authored prompt sets, a judging pass (the paper used LLM judging over 47,880 responses), and API or inference spend proportional to the number of languages and cue conditions; no retraining or infrastructure change is required. It can fail in three ways: judge models may grade Indic responses less reliably than English ones, cue manipulations may not capture real deployment distributions, and observed refusal gaps may reflect translation artifacts or uneven multilingual safety tuning rather than evaluation awareness per se.

3DCodeVerse: Exploring 3D Worlds as Code

The method replaces manual 3D asset authoring and single-pass LLM 3D code generation with a multi-agent DAG harness that iteratively generates, executes, measures, and visually verifies executable 3D programs, plus a 2M-sample dataset for fine-tuning open models. FDE-Gym: The Last Mile of AI Delivery

FDE-Gym replaces well-specified issue-ticket agent benchmarks with 95 ambiguous delivery tasks in simulated customer environments, scored by improvement in the customer's own business metric with penalties for stakeholder interactions. Ajar: Measuring Open Privilege in Agent Defenses

safety and guardrails · test · 2 of 3 implementations are independent

Ajar replaces the two-axis evaluation of agent defenses (attack success and benign utility) with a third axis that directly measures privilege left open, by injecting unneeded candidate tool calls into existing benchmarks such as AgentDojo. It costs benchmark instrumentation per task and additional evaluation runs on top of the benchmark the team already uses, plus engineering to generate valid-but-unnecessary tool calls from tool schemas and reference solutions. It can fail if the generated candidate calls do not reflect realistic privilege escalation in the team's actual tool surface, or if a defense appears tight only because it over-refuses legitimate calls, a trade-off the metric exposes but does not resolve.

Zero-Shot Self-Orchestration with Ledger-Based Control for Improved LLM Coding Performance

The method replaces single-pass LLM code generation with a manager-worker scaffold in which short worker calls share state through a filesystem ledger, requiring no training or per-benchmark tuning. It roughly triples the token bill per problem, though it can buy accuracy more cheaply than upgrading to a larger model and is self-hostable on a 24 GB GPU only via small open-weight workers such as Qwen-27B-class models. It can fail because gains are strongly model-conditional: some models show null or negative deltas (e.g., Qwen3.6-35B, -1 to -9 points with reasoning off), and large reasoning-enabled models gain little, so the extra token cost may buy nothing on a given workload.

The Empire, Long Divided, Must Unite: Architectural Convergence in Three LLM Agent Harnesses

This source-level study replaces ad hoc agent-loop implementations with a converged five-element harness design: a commoditised loop, an append-only replayable session record, model quirks kept as data, progressive context disclosure, and explicit extension seams. The cost is implementation effort: building the replayable record and extension seams adds engineering complexity, and the paper provides no measured performance benefit, only architectural evidence from three case harnesses. Knowledge Distillation from Neural Networks to Differentiable Logic Networks

The method replaces training a differentiable logic network (DLN) classifier directly with a two-phase distillation procedure from a trained MLP teacher, which is discarded after training so inference retains the DLN's interpretability, sparsity, and very low gate-level cost. The cost is added training complexity: a two-phase loop and tuning of distillation weight and temperature, with four investigated variants including a joint hyperparameter-architecture search; inference cost and model size are essentially unchanged. The benefit is dataset-dependent (up to 15% balanced-accuracy gain, varying across the 20 tasks), DLNs still underperform conventional networks on several datasets, and the approach applies only to tabular classification where DLN architectures and their immature ecosystem are viable.

DARIC: A Position-Independent KV Cache Reuse System with Distribution-Aware Recomputation

DARIC replaces full prefix prefill (and prior recomputation-based cache-reuse methods such as CacheBlend-style approaches) for repeated long contexts by storing position-independent KV caches and recomputing only a subset of tokens selected by empirical KV-deviation distributions, with a lightweight architecture intended to integrate with standard inference engines like vLLM. Costs include storing and managing reusable KV caches per document chunk, added integration and token-selection logic in the serving stack, and a residual recomputation pass whose overhead depends on the selected token fraction. It can fail when prefix reuse patterns are rare (unique or non-overlapping queries yield no benefit), when the assumed deviation distribution does not hold for a given model or tokenizer, or when third-party APIs are used, since the method requires access to KV-cache internals unavailable through black-box endpoints.

RoleWalk replaces learned or whole-graph-dependent structural role embeddings (struc2vec, Role2Vec, GraphWave, Digraphwave) with a training-free, neighbourhood-local embedding built from short lazy random walks, which makes coordinates comparable across graphs. Robust Deep Prototype Classifiers via Lipschitz Training

The method replaces an unconstrained embedding network feeding a linear, SVM, or GLVQ classification head with a Lipschitz-constrained embedding paired with a prototype-based head, extending the prototype margin certificate into input space as an ε/L robustness bound. Replaces BF16/FP16 KV cache attention with end-to-end NVFP4/MXFP4 decoding, combining dual-residual query quantization, underflow-aware probability scaling, and outlier-aware key quantization with fused transposed-softmax kernels on paged caches. multi-agent orchestration · test · 5 of 5 implementations are independent · 5.2x gain in cost (reported by the authors; not independently verified)

The method replaces single-pass LLM code generation with a manager-worker scaffold in which short worker calls share state through a filesystem ledger, requiring no training or per-benchmark tuning. It roughly triples the token bill per problem, though it can buy accuracy more cheaply than upgrading to a larger model and is self-hostable on a 24 GB GPU only via small open-weight workers such as Qwen-27B-class models. It can fail because gains are strongly model-conditional: some models show null or negative deltas (e.g., Qwen3.6-35B, -1 to -9 points with reasoning off), and large reasoning-enabled models gain little, so the extra token cost may buy nothing on a given workload.

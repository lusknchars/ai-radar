MetaKV: Adaptive KV Cache Compression for Constrained LLM Inference

MetaKV replaces a single fixed KV cache compression configuration with per-prompt selection among existing methods (KVQuant, H2O, RocketKV, FP16) guided by lightweight predictors of latency, peak memory, and correctness. The cost is training and maintaining three prediction models plus a selection step per prompt, adding engineering complexity and a small inference-time overhead on top of the underlying compressors. It can fail if the accuracy or latency predictors mispredict on out-of-distribution prompts or on hardware and models different from the evaluation setup, causing constraint violations or suboptimal choices.

MTVA-Bench: Evaluating the Language Model Inside Cascaded Voice Agents

MTVA-Bench replaces end-to-end voice pipeline scoring and generic LLM benchmarks with an isolated evaluation of the language model under realistic call conditions (ASR errors, split utterances, script and language constraints), using an LLM caller, a mock backend, deterministic tool-call checks, and two citation-requiring LLM judges across 490 scenarios in 7 languages. SWE-Duel: Towards a Self-Scaling Arena for Coding Agents

SWE-Duel replaces static, leak-prone coding benchmarks (e.g., SWE-bench-style fixed task sets) with evaluation-time task generation, where agents alternately author buggy pull requests and review each other's under mirrored Red-Blue turns with test-based oracles. Random Attention: Rethinking KV Cache Eviction for Efficient Reasoning

Random Attention replaces score-based KV cache eviction policies (such as H2O-style importance scoring) with uniform random eviction within each attention head, while always retaining the prompt, eliminating all per-token scoring computation. It costs nothing in memory or latency beyond the eviction itself and adds almost no implementation complexity, since the selection signal is removed entirely; quality is reported to match the best prior evictor on reasoning workloads. It can fail on workloads where the reasoning trace does not restate needed information or where redundancy across heads is insufficient, and on non-reasoning tasks or cache configurations where the prompt is not the dominant fragile component, since the findings are validated on reasoning traces with long chains of thought.

One Model to Loop Them All: Elastic Latent Recurrence for Language Models

The method replaces the standard practice of serving a fixed-depth non-recurrent transformer (or maintaining separate checkpoints per accuracy/latency tier) with a single recurrently applied block whose loop count is chosen at inference, while removing the usual one-loop accuracy penalty through gated state updates, mixed loop counts in training, and loop-index conditioning. The cost is that the gains require modifying pretraining: the recipe must be trained in, and all reported results come from models the authors trained themselves, including a late-stage mixed-depth schedule that still adds training compute. It can fail for a constrained-infrastructure adopter because no pretrained foundation model can be retrofitted with ELR via fine-tuning alone with validated results, the accuracy-per-loop gains on downstream production workloads are unverified outside the authors' benchmarks, and multi-loop serving multiplies per-request latency and compute on a single 24 GB GPU where a 4B-class model is already near the practical ceiling.

Contextual Correction of Parallel Draftsfor Speculative Decoding

DCOCO replaces the top-1 commitment of parallel diffusion-based drafters (e.g., DFlash) by retaining multiple candidate tokens per draft position and scoring their contextual compatibility across adjacent positions in parallel, restoring intra-block dependencies without sequential drafting. Coral-KV replaces clustering-based video KV-cache quantization (e.g., QVG-4/QVG-Pro) with cross-layer prediction: compact block-diagonal-plus-low-rank predictors estimate keys and values in later layers from earlier cache states, and only the residuals are quantized. Tram-FL replaces conventional decentralized federated learning, where every client holds a model copy, updates it locally, and exchanges and aggregates copies, with a single model circulated sequentially among nodes along a scheduled route with allocated update iterations and quantized momentum.

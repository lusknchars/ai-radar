RIT-RAG: Navigating Document Corpora with Retrieval-Induced Trees

RIT-RAG replaces flat chunk retrieval and single-document structure navigation (e.g., PageIndex) with a hybrid: broad chunk retrieval induces sub-trees from per-document table-of-contents/sitemap trees, which an LLM agent then navigates and selectively reads. Costs include an offline tree-construction pipeline per document, additional LLM agent calls for navigation, node reading, and query reformulation (higher latency and API spend per query than vanilla RAG), plus engineering complexity in maintaining document-structure extraction. Failure modes include documents lacking reliable TOCs or sitemaps, retrieval proposing poor starting positions that mislead the induced sub-tree, and agent navigation errors accumulating over multiple steps, which may not justify the gains on small or weakly structured corpora.

Automated Regulatory Compliance Question Answering in Financial Services with Domain-Adapted Retrieval-Augmented Generation

Replaces off-the-shelf dense or BM25 retrieval and prompted compact LLMs with a LegalBERT retriever tuned via entailment reformulation, contrastive in-batch negatives, and BM25 score fusion, plus optional RAFT-LoRA on a quantized 2B-12B generator, all feasible on a single 24 GB GPU. Chronicle: Cut-Point Replay for Regression Testing of LLM Agents

The method replaces ad-hoc manual reproduction of agent failures and full live re-runs with recorded envelopes at model and tool boundaries, replayed selectively so that only the code under test executes live, turning each incident into a deterministic CI regression test. The cost is instrumentation of all non-deterministic boundaries, storage of immutable run records, and 23 microseconds of recording overhead per crossing, plus the engineering effort to maintain replay-compatible boundaries as the agent evolves. It can fail when trajectories drift so that the recorded suffix no longer matches the new code's live prefix, when tools or models change their interfaces, and because the evidence base is only six incidents with simulated model boundaries, leaving real-model fidelity unproven.

MineralExp: Benchmarking LLM Agents for Experimental Design in Real-World Mineral Exploration

MineralExp replaces unstructured human judgment of open-ended experimental designs with a 19-type taxonomy that converts experimental design into deterministic multi-label classification, supplemented by an LLM-as-a-Judge metric. WETW: Learning Pair-Specific Weighted Euclidean Distances for Efficient DTW Search

WETW-FV replaces exact quadratic-cost DTW computation over full collections (and weak lower-bound pruning) with a learned filter-and-verify pipeline: a trained encoder (WESEE) embeds series, a small symmetric network predicts pair-specific per-dimension weights for a weighted Euclidean shortlist, and exact DTW verifies only shortlisted candidates. The method replaces hand-written quantized matmul kernels in GGML/llama.cpp with Halide programs where encoders and decoders are ordinary schedulable stages fused into register tiles via the approximate_by directive, generating hundreds of kernels from one algorithm and schedule library. RIT-RAG: Navigating Document Corpora with Retrieval-Induced Trees

retrieval and RAG · test · 2 of 3 implementations are independent

RIT-RAG replaces flat chunk retrieval and single-document structure navigation (e.g., PageIndex) with a hybrid: broad chunk retrieval induces sub-trees from per-document table-of-contents/sitemap trees, which an LLM agent then navigates and selectively reads. Costs include an offline tree-construction pipeline per document, additional LLM agent calls for navigation, node reading, and query reformulation (higher latency and API spend per query than vanilla RAG), plus engineering complexity in maintaining document-structure extraction. Failure modes include documents lacking reliable TOCs or sitemaps, retrieval proposing poor starting positions that mislead the induced sub-tree, and agent navigation errors accumulating over multiple steps, which may not justify the gains on small or weakly structured corpora.

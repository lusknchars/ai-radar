In-Model Context Compression with Agentic Soft Tokens for Long-Horizon LLM Agents

ASTC replaces external trained context compressors and hard-token rewriting by using the model's own GDN recurrent state to carry absorbed context as soft tokens alongside exact hard tokens, reducing later-layer attention computation and yielding reusable KV caches. CRoS: Causality Reward on Scrambled CoTs Improves Accuracy and Reasoning Faithfulness

CRoS replaces outcome-only RLVR rewards and perturbation-based causality rewards with a causality metric that scrambles the order of reasoning steps without altering step content, rewarding CoTs that causally drive the final answer. The cost is substantial: it requires running reinforcement learning with verifiable rewards on a reasoning model, including generating multiple CoT rollouts, scrambling steps, and re-querying the model to measure answer changes, all of which multiply compute per training step well beyond standard fine-tuning. Failure modes include reward hacking where the model learns to produce CoTs that merely appear order-sensitive, degraded performance on tasks where step order is naturally flexible, and the confound that some valid reasoning is genuinely order-invariant, in which case the metric penalizes correct behavior.

SecPO: Principled Adversarial Training for Prompt Injection Security

Replaces DPO-based prompt-injection defense training (e.g., Meta-SecAlign) with the SecPO loss anchored on an approximated injection-invariant reference model plus an adversarial training pipeline that synthesizes strong best@240 injections. Costs are a full adversarial fine-tuning run with attack synthesis (240-step optimization per sample) on a 27B model, which likely exceeds a single 24 GB GPU without third-party training APIs, though the released model and training data are freely usable. Can fail against novel adaptive attacks outside the training distribution, and reported gains are validated mainly on the authors' attack suite and AgentDojo benchmark.

Subquadratic Attention with a Hierarchical Tree-Structured Indexer

ZHA replaces quadratic full attention (and sparsity methods whose indexers scale quadratically) with a hierarchical tree of compressed key summaries over the KV cache, which queries traverse top-down to retrieve a sparse key subset. Cost: the tree must be built and maintained over the KV cache, adding memory and implementation complexity, and adapting an existing pretrained model requires a KL distillation stage over a few billion tokens plus custom traversal kernels to realize the theoretical gains. What can fail: the benefit only materializes beyond roughly 1M context where the reader's single 24 GB GPU cannot operate anyway; routing errors from compressed summaries can degrade retrieval and reasoning quality; and there is no mature open-source implementation or hardware-efficient kernel yet, so realized speedups may fall far short of the performance model.

RoboArchitect: Automating the Design of Robotic Agents with Persistent Memory

The technique replaces manual hand-coding of agent harnesses and policy finetuning by using a coding model to iteratively diagnose rollout failures and revise control code around frozen policies. Code That Works, Environments That Don't: Measuring Environment Reproducibility in AI-Generated Software

agent evaluation · adopt · 1 of 2 implementations is independent

The method replaces reliance on functional test pass rates as the sole quality gate for AI-generated code by adding a three-layer dependency audit (declared, runtime-installed, necessary-and-sufficient). It costs only containerized build-and-run cycles per generated project, plus an agent protocol for environment specification, fitting within a single-GPU or API-only budget. It can fail if applied without pinning runtime behavior, since runtime-installed dependencies vary with resolver versions and base images, and the audit detects misspecification but does not itself correct it.

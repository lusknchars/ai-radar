ProgramGym: Scaling Training Environments for Long-Horizon Program Reproduction Agents

Program-Agent replaces a single monolithic coding-agent loop with a role-isolated workflow (analysis, implementation, review) plus revision management for compilation checks and failure recovery, which a small team can replicate as prompting/orchestration over API models; Program-Env replaces hand-built training environments with a feedback-driven pipeline that repairs sandbox builds and black-box tests. The agent-side cost is higher token consumption and latency from multi-role passes and exploratory analysis before implementation; the environment-side cost is substantial engineering and compute to build and verify 1,648 sandboxed repositories, which is not realistic on one 24 GB GPU. Failure modes include compounding errors across role handoffs, reference exploration that consumes context without improving the implementation, and environment/test suites whose black-box tests are too weak to verify correctness, so reproduced gains may not transfer to benchmarks other than ProgramBench.

This work does not replace a production method; it adds a 50-task benchmark for measuring whether LLM agents circumvent runtime monitors under ordinary task pressure, which can replace ad hoc or absent evaluation of monitor robustness. AgentSWE: Can Coding Agents Build the Agent You Actually Want?

AgentSWE replaces ad hoc acceptance of agent-generated agent code with commission-style evaluation: a frozen submission is tested on held-out cases graded against requirement-derived rubrics under pass/fail gates, rather than being judged by its behavior on the illustrative cases the builder saw. The cost is evaluation engineering effort: constructing held-out cases and rubrics per requirement, plus the API or GPU spend to run frozen submissions, and it measures rather than improves delivered quality. It can fail to transfer if the reader's tasks are narrower than the benchmark's 25 commissions, and rubric-based grading inherits the reliability limits of whatever grader is used.

Surfing the Activation Wave: Analyzing the Information and Geometry of LLM Hidden States for Speculative Decoding

The method replaces fixed, position-based heuristics for choosing which decoder layers feed the draft model in EAGLE-style speculative decoding with a data-driven selection based on matrix entropy (informativeness), CKA (diversity), and token-entropy filtering. Rollout-Time Intervention: Unlocking Agentic Reinforcement Learning Beyond Policy Limits

RTI replaces purely on-policy exploration in agentic RL by injecting reward-rubric evidence during rollout to convert failed trajectories into successful ones, then filtering interventions with excessive distributional shift before policy optimization. DREAM replaces external memory-isolation or continuous online-auditing modules for defending LLM agents against memory poisoning with an agent-intrinsic, training-free three-stage pipeline (perturbation-induced reactivation, anomaly diagnosis, selective memory suppression and reinforcement). It replaces autoregressive left-to-right generation in tool-using agents with iterative masked-diffusion denoising over interleaved reasoning and tool-call trajectories, so tool decisions are conditioned on full-trajectory bidirectional context rather than only the past. RAMP: Recurrent Adaptive Mixed Precision for Efficient Prefill in Recurrent-Depth Language Models

RAMP replaces uniform-precision recurrent prefill with a schedule that runs early recurrent steps in low-precision weight-and-activation arithmetic and restores full precision for terminal steps, exploiting the finding that early quantization errors are attenuated by later refinement. Monarch-MoE replaces the dense low-rank factors in multi-expert LoRA adapters with block-diagonal factors joined by a fixed permutation, so each block-pair update touches only one output block and forgetting is reduced in multimodal continual instruction tuning. DUALQUANT replaces calibration-data-dependent activation quantization (e.g., SmoothQuant) and weight-only quantization with a calibration-free dual-scale method derived from weight-reconstruction MSE minimization, supporting MX and NVFP4 block formats. ReplaySSM: Cache SSM Inputs, Not State

It replaces eager per-step SSM state reads/writes with a periodically updated checkpoint plus a buffer of recent SSM inputs, decoupling output computation from state updates and enabling cheap speculative rollback and split-precision checkpoints. The cost is additional implementation complexity in the serving stack (currently a vLLM patch for Mamba-2 and Gated DeltaNet), memory for the input buffer, and dual checkpoint copies when split precision is used. It can fail if checkpoint staleness degrades outputs for long unroll intervals, if the reader's model architecture lacks support in the implementation, or if batch sizes are too small for state I/O to be the bottleneck, in which case the measured gains do not transfer.

OccludeBench: Can VLMs Find What's Missing?

The technique replaces single-pass question answering about occluded objects with a two-step procedure in which the model first generates a candidate hidden object via inpainting and then evaluates that hypothesis against the visible physical cue. It costs an extra image-generation call and a second verification pass per query, and it is only available on models with image-generation capabilities; extended reasoning, tool use, and few-shot prompting were shown not to work reliably as alternatives. FORTE: A Production Framework for Feature Evaluation and Deprecation in Industrial Recommender Systems

FORTE replaces ad hoc or importance-score-based feature removal with a model-agnostic pipeline of efficient perturbation scoring, grouped ablation over candidate feature sets to capture interactions, lineage tracing of downstream consumer models, and offline-to-online validation before deprecation. ProgramGym: Scaling Training Environments for Long-Horizon Program Reproduction Agents

coding agents · test · 3 of 3 implementations are independent

Program-Agent replaces a single monolithic coding-agent loop with a role-isolated workflow (analysis, implementation, review) plus revision management for compilation checks and failure recovery, which a small team can replicate as prompting/orchestration over API models; Program-Env replaces hand-built training environments with a feedback-driven pipeline that repairs sandbox builds and black-box tests. The agent-side cost is higher token consumption and latency from multi-role passes and exploratory analysis before implementation; the environment-side cost is substantial engineering and compute to build and verify 1,648 sandboxed repositories, which is not realistic on one 24 GB GPU. Failure modes include compounding errors across role handoffs, reference exploration that consumes context without improving the implementation, and environment/test suites whose black-box tests are too weak to verify correctness, so reproduced gains may not transfer to benchmarks other than ProgramBench.

Higher-order pruning of experts in mixture-of-experts language models

HOPE replaces first-order expert-importance pruning criteria (e.g., REAP) with a second-order objective that accounts for cooperative interactions between experts when deciding which to remove. It costs additional calibration computation to estimate interaction terms, requires access to a representative calibration set, and does not reduce the non-expert portion of the model, so memory savings are limited to the pruned expert parameters. MemFit: Efficient Long-Term Agentic Memory

MemFit replaces LLM-driven memory construction and consolidation (as in MemGPT-style systems) with verbatim append-only turn storage, segment-summary indexing, and LLM-free retrieval combining lexical and semantic signals with cross-encoder reranking. Costs include an ever-growing raw store with associated embedding and reranking infrastructure, retrieval latency from the multi-path pipeline plus cross-encoder stage, and the engineering complexity of maintaining the indexing stack. Weaken to Strengthen: Weakening-Induced On-Policy Self-Distillation for Large Reasoning Models

WISD replaces self-distillation methods that require privileged information or external teachers by training the model to minimize divergence from a weakened copy of itself created via low-bit quantization or magnitude pruning, using only unlabeled prompts. The cost is doubled memory during training (hosting both original and weakened models) plus computational overhead for the contrastive loss, though the weakened copy can reuse quantized weights efficiently. Post-adoption risks include divergence from the original model’s distribution leading to catastrophic forgetting, and sensitivity to the degradation level—if the weakened model is too corrupted, the contrast signal becomes noisy and training destabilizes.

Security Impact of Coding Agent's Memory Files

The paper does not propose a technique that replaces an existing method; it characterizes project memory files (e.g., CLAUDE.md) as an injection channel that can steer coding agents, finding only small, inconsistent effects on secure completions (-8 to +6 points) but large differences in whether agents disclose the file's influence. The practical cost to the reader is process, not compute: treat memory files as untrusted code-adjacent input, gate them behind the same review as source changes, pin or hash approved versions in the repository, and require agents to disclose which files shaped their output. What can fail: the study shows flagging a malicious memory file does not reliably prevent vulnerable code, and disclosure behavior varies by agent, so review-based mitigations reduce but do not eliminate the risk.

Two-Stage Clipping: Linear-Time Approximate and Exact Mixed-Norm Projections for Transformers

TSC replaces exact proximal solvers for ℓ1,∞ mixed-norm projection—used to induce column-wise structured sparsity in Transformer weight matrices—with a two-stage approximate operator: a group-level budget projection followed by per-group coefficient clipping, computable in O(nm) time (O(n²) for square attention matrices). The cost is that the operator is an approximation, not the exact projection: the paper bounds the Euclidean discrepancy to the true proximal solution and reports it is small on synthetic data, but it is nonzero by construction, and it targets the projection operator itself rather than delivering an end-to-end pruned model. What can fail: the sparsity levels at which the approximation error stays acceptable for downstream accuracy are not established on production-scale LLMs in the abstract, integration requires a sparsification-aware training or pruning pipeline the reader may not have, and the runtime benchmarks are synthetic, so realized gains on real model compression workloads need validation on the reader's own matrices and tolerance for approximation error.

Thinking Fast, Anywhere: One System-1 for the Decision Points of Any Agent Workflow

The method replaces per-step invocations of a large LLM for routine enumerable decisions with a single 4B System-1 model that resolves them in one forward pass, escalating to the large model only below a calibrated confidence threshold. The cost is an offline pipeline that mines decision points from over 1,000 skills, collects execution-grounded trajectories in isolated containers, and trains the 4B pointer model, plus an extra local model to host at run time. Failure modes include miscalibrated thresholds causing either silent wrong decisions or excessive fallback to the large model, and degraded coverage on workflows whose decision points differ from those represented in the mined skill corpus.

It replaces forward-only memory/reflection harnesses (and replay- or validation-based harness optimization) with a strictly online scheme that, after each streamed instance, revises previously retrieved reflections using the resulting trajectory as backward feedback. When the World Is the Test Suite: Agentic Intelligence for the Physical World

The paper proposes treating physical trials, simulators, learned judges, and formal checks as the 'test suite' for robot and lab code, replacing ad hoc or absent verification of programs written by coding agents for physical actuators. The cost is the expense and potential unreliability of physical evidence: real-world trials are costly and slow, while cheaper substitutes (simulators, learned judges, traces) can be wrong or gameable under search, and building a physical continuous-integration pipeline requires ongoing maintenance of skill libraries and evaluation infrastructure. What can fail is verification drift: learned or simulated judges diverge from real-world behavior, so programs validated cheaply may fail on hardware or violate safety constraints that task success alone does not capture.

DAQ: Decision-Aligned Post-Training Quantization for Spiking Transformers

DAQ replaces standard post-training quantization of spiking transformers with a decision-aligned calibration that keeps quantized membrane variables inside the floating-point model's firing regions along the quantized model's own trajectory. It requires only calibration data and no retraining, enabling 4-bit weights and membrane variables, but adds a state-trajectory-dependent calibration procedure more complex than generic PTQ. It can fail when firing decisions near decision boundaries diverge over recurrent time steps, and its energy benefits depend on spiking or neuromorphic deployment targets rather than conventional GPU inference.

Contextual Correction of Parallel Draftsfor Speculative Decoding

DCOCO replaces the top-1 commitment of parallel diffusion-based drafters (e.g., DFlash) by retaining multiple candidate tokens per draft position and scoring their contextual compatibility across adjacent positions in parallel, restoring intra-block dependencies without sequential drafting. CANDID: Candidate-Driven Intervention for Disciplined Execution in Local Computer-Use Agents

CANDID replaces textual self-reflection and unguarded action loops in computer-use agents with structural execution controls: parallel candidate sampling filtered by a loop-recovery mechanism at failure-prone steps, plus a unanimous-consensus gate before the agent may declare DONE. It replaces generic INRs trained on domain-wide random mini-batches with low-rank neural representations (shared basis matrices plus a small hypernetwork emitting per-layer coefficients) trained on spatially local mini-batches drawn from single AMR cells and time snapshots. This is a measurement framework for context-management policies (adding retrieved code, removing stale tool observations) in coding agents, replacing ad hoc prompt engineering decisions and naive token counting with cost accounting that separates uncached input, cached input, and output tokens. BQ-LoRA replaces the FP16 low-rank adapters used in QLoRA with 1-bit binarized adapters plus a learned per-layer scale and a Scaled Straight-Through Estimator, while keeping the 4-bit quantized base model unchanged. InfuseLoop: Cross-Trajectory Latent Injection for Scalable Parallel Looped Transformers

InfuseLoop replaces the standard PLT loop recurrence, in which only the preceding in-trajectory hidden state crosses loop boundaries, with a cross-trajectory latent injection that aggregates causally available hidden states from later prediction trajectories via lightweight attention residuals. Costs are O(Rd) additional hidden-state storage, 0.3% decoding time over vanilla PLTs, and 23.3% over a non-looped baseline, while preserving token-parallel training and the vanilla PLT KV-cache footprint. It can fail if the reported stability and perplexity gains do not transfer beyond the paper's training scale, if looped-model decoding underutilizes the reader's single-GPU serving stack, or if integrating trajectory cross-dependencies complicates existing inference kernels.

HADVQ: Hessian Aware Directional Vector Quantization

HADVQ replaces scalar ultra-low-bit weight quantization (e.g., GPTQ-style per-channel rounding) with polar vector quantization using an E8-lattice codebook after random preconditioning, plus Hessian-proxy detection of sensitive channels preserved at higher precision for 0.16 extra bits. The cost is a complex offline quantization pipeline (preconditioning, polar decomposition, lattice codebook construction, Hessian estimation), non-standard decoding kernels that may lack mature inference-engine support, and a modest bit-rate increase for the protected channels. Failure modes include accuracy degradation if the proxy Hessian misidentifies important channels, latency regressions if lattice decoding is not efficiently implemented on the target GPU, and gains that may not transfer to models or calibration data distributions different from those evaluated.

LoopZip replaces full-length visual token sequences in looped (weight-shared) VLMs with a compressed set built from pre-backbone aggregation, cross-invocation attention-based token selection, and weight-tied value correction, all without additional training. SpecLook replaces the sequential think-with-images loop of zoom-in tool calls in agentic MLLMs with a training-free three-level pipeline: a small model drafts a region glimpse and re-answers, the large model verifies and corrects the glimpse without tools, and only unresolved questions reach a single forward pass of the agent, skipping the iterative loop entirely. It costs an additional small-model draft inference plus fusion and verification logic, and requires serving two models or routing tiers, which adds engineering complexity even though it is training-free. It can fail when the small model's glimpse is confidently wrong yet consistent with the large model's corrected interpretation, and the claimed speedups are tied to high-resolution visual grounding benchmarks, so workloads without fine-grained image detail may see little benefit.

LProp: Propagating Latent Uncertainty through Evidence-Conditioned Belief Revision in LLM Agents

LProp replaces passing scalar confidence scores or verbose textual reflections between agent stages with compact latent-space uncertainty representations, and revises downstream answer distributions as new evidence arrives without extra trajectory sampling. The cost is the need for access to model internals (hidden states), which rules out closed third-party APIs, plus added pipeline complexity and an estimator component that must be trained or fitted. It can fail when the latent estimator miscalibrates on out-of-distribution tasks, when upstream errors are too severe for belief revision to recover, or when the reader's production models are API-only, making the method inapplicable.

ARISE: Practical Self-Evolving Memory for Accurate and Cost-Efficient Enterprise Agents

ARISE replaces manual prompt and workflow refinement after agent failures with an automated loop that attributes failures, stores corrections as retrievable micro memories, consolidates them into macro rules, and accepts rule updates only when held-out accuracy improves, all without changing model weights, tools, or workflow logic. It costs extra attribution and consolidation calls (optionally to a stronger teacher model such as Claude Opus), a memory store with retrieval added to each inference, and the engineering of an evaluation gate, though it slightly reduces model calls and output tokens at deployment. It can fail if the self- or teacher-attribution misdiagnoses errors and pollutes memory with harmful rules, if the held-out set is unrepresentative so accepted rules do not generalize, or if retrieved memories degrade as workflows and underlying models change.

MANGO Arena: Same Seeds, Different Chains Evaluating LLM Agents in a Disrupted Supply Chain

MANGO Arena replaces ad hoc single-metric agent evaluation with an open-source testbed that jointly measures economic outcomes (bullwhip effect), rule adherence, and collusion attempts in a four-agent serial supply chain, alongside explicit reporting practices for multi-agent runs. Adoption costs are modest in compute (small reasoning models via API) but real in engineering effort: the harness must distinguish API failures from genuine agent decisions and requires enough seeds and reruns to draw stable conclusions. The paper itself demonstrates the main failure mode: with only three seeds, upstream bullwhip measurements varied up to 17x between identical reruns, so conclusions about model behavior under disruption did not survive repetition.

Weight Space Programming for Vision Language Model Repair

The technique replaces gradient-based retraining or checkpoint rollback for repairing corrupted model weights with a coding agent that edits the weight tensors directly. It costs only an agent session with API or local inference access plus the baseline weights for verification, so it fits constrained infrastructure, but it adds a fragile manual diagnostic loop rather than a reliable automated procedure. It fails when faults leave no detectable trace: after rounding away 32-bit residue in the low bits of 16-bit weights, unaided repair largely collapses, row or column permutations are never found within budget, and noise faults go undetected on the larger model.

Beyond Replacement: Levenshtein Editing for Diffusion Language Models

LED replaces replacement-only token editing in diffusion language model decoding with Levenshtein-style insertion, deletion, and replacement, trained via on-the-fly LCS-based edit supervision and multi-stage fine-tuning rather than annotated labels. The cost is a post-training pipeline on a 16B-parameter model, including multi-stage training where each stage's output feeds the next, which is impractical on a single 24 GB GPU and adds modest per-forward decoding overhead (6.14 to 7.05 tokens per forward). It can fail if applied to models whose base decoding already saturates, if the reconstructed edit supervision misaligns with true error modes, or if confidence-guided decoding is already available, since the largest gains appear in the confidence-free setting.

Thinking Fast, Anywhere: One System-1 for the Decision Points of Any Agent Workflow

distillation · test · 3 of 4 implementations are independent · 4x gain in cost (reported by the authors; not independently verified)

The method replaces per-step invocations of a large LLM for routine enumerable decisions with a single 4B System-1 model that resolves them in one forward pass, escalating to the large model only below a calibrated confidence threshold. The cost is an offline pipeline that mines decision points from over 1,000 skills, collects execution-grounded trajectories in isolated containers, and trains the 4B pointer model, plus an extra local model to host at run time. Failure modes include miscalibrated thresholds causing either silent wrong decisions or excessive fallback to the large model, and degraded coverage on workflows whose decision points differ from those represented in the mined skill corpus.

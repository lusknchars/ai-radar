Lost in Implicit Routing: How LLM Agents Fail to Load Relevant Skills at Scale

Explicit preselection of relevant skills before agent execution replaces implicit routing, in which the agent scans full skill metadata and decides what to load during the task. It costs an additional selection step with its own latency and coverage trade-offs, and requires a mechanism (retriever or selector model) to pick candidate skills from the library. It can fail when the preselector misses the golden skill, since the agent then has no opportunity to recover it, and gains shrink when libraries are small enough that implicit routing has not yet collapsed.

Judges Follow the Reference: The Derivation Gap in Verifying Tool-Call Arguments

DeRef replaces giving the judge raw (possibly truncated or reference-free) conversation history by having a separate model read the full history without seeing the candidate argument and write an explicit reference stating what the value should be. It costs one additional model inference per judged argument, adding latency, API or GPU cost, and a new pipeline component. It can fail when the reference-writing model itself misderives the intended value, since judges are shown to follow the visible reference even when it is incorrect, so a wrong reference can systematically flip verdicts.

Factorized Context Attention: From Emulated to Native Grid Probing

Factorized Context Attention replaces grid probing's repeated per-span re-encoding with a native block-sparse attention pass that encodes the input once into a shared KV cache and reads all local and strided spans in one batched forward. It costs a custom attention implementation with masking plus a stair position schedule, rather than any training or extra parameters. It can fail where the block-sparse pattern is unsupported by the reader's inference stack, where spans straddle the trained position range despite the schedule, or where tasks need dense cross-span interactions that strided probing misses.

AIChipBench: Benchmarking LLM Agents for Automated AI Accelerator Design

AIChipBench replaces ad hoc or output-only evaluation of LLM coding agents for hardware design with an executable integer reference that exposes stored-state mismatches at every decoding step, plus held-out grading on new token sequences, resets, memory stalls, and synthesis. It costs the effort of building step-level reference state and substantially expanded final test suites rather than relying on public output tests, and it does not itself provide an adoptable tool or model. The demonstrated failure mode is directly relevant to agent evaluation generally: designs pass output tests while corrupting internal state, with 45 of 69 accepted designs failing under regrading, so any agentic workflow the reader adopts should use state-level or intermediate feedback and final tests well beyond development cases.

ICLWorld: Benchmarking In-Context Learning of Agents from Digital to Physical Worlds

ICLWorld replaces offline, text- or static-image-based, contamination-prone agent evaluations with an online benchmark of 160 tasks across 30 digital and physical environments, accessed through a unified UI harness. What Does a Skill Vocabulary Cost? A Closed-Loop Decomposition over Demonstrated Motions

MPQ replaces the jointly learned latent codebook inside a skill policy with an external library of demonstrated motion prototypes, snapping each predicted action chunk to its nearest library element and correcting it toward the prediction within a bound, with no trained parameters. It costs a nearest-neighbor lookup and stored demonstration library at execution time, adds no training overhead, and the paper reports no measurable closed-loop performance loss across six architectures including a 7B VLA model. It can fail to transfer if the library does not cover the deployment distribution, and its offline reconstruction metrics are shown to misjudge library size, design, and cross-benchmark transfer, so validation must be closed-loop.

Bathys: Advancing Deep Search Agents

The technique replaces single-pass retrieval or shallow agentic search with a trained deep search agent that iteratively reformulates queries, gathers evidence chains, and verifies answers via an SFT, KTO, and compaction-managed RL pipeline. Online environment repair replaces reward-penalty, rollout-filtering, and static pre-training verifier hardening by asynchronously patching exploited test harnesses during RL training while leaving triggering rewards unchanged. LLM Agent Authorization Across Context Compaction

The technique replaces letting the authorizer derive its policy from the compactor's model-written summary (which conflates user text with injected content) with deriving policy only from user messages authenticated on arrival and carried verbatim across the compaction boundary, while the agent still reads the summary for context. It costs engineering effort to thread authenticated user text through the agent framework and gives the attacker a denial-of-policy option: they can block policy derivation but cannot shape it, and compaction quality for the agent itself is unchanged. It can fail where the agent framework does not expose a trust boundary between user turns and summaries, where legitimate user intent spans content that arrived as tool output rather than user text, or where authorization of requests beyond the frozen/derived per-request policy is needed.

The technique replaces unchecked acceptance of permission-prompt answers and policy updates from plugins and remote services with an enforced update step that either permits only updates preserving every currently denied call, or attributes each rule to its author and lets parties remove only their own restrictions. SkillCore replaces runtime skill loading—external procedural guidance injected into agent prompts—with supervised fine-tuning on agent trajectories whose skill-loading scaffolding has been removed, so the model executes the procedures directly. Norn: Context-Length-Aware Optimization of Weight and KV Cache Placement for Offloaded LLM Inference

Norn replaces static weight and KV-cache offloading schedules (as in FlexGen-style pipelined sharding) with context-length-aware execution plans that switch at precomputed points during decoding, plus operator-major chunked prefill to avoid repeated weight transfers. SPRUNN: Structural Proximity for Pruning in Deep Neural Networks

SPRUNN replaces magnitude-based or heuristic filter-importance criteria with a structural-proximity measure that compares each convolutional filter against all others to identify redundant filters, combined with fine-grained pruning of fully connected layers and a refined learning-rate schedule during retraining. It costs an offline pruning-plus-retraining pipeline: compute for filter-similarity computation, fine-tuning cycles to recover accuracy, and added complexity in maintaining a pruned variant alongside the base model; on a single GPU this is feasible but adds engineering effort. Beyond Hard Tokens: Predictive Memory for Multimodal Protein Generation

PredMem replaces the stateless mask reset in iterative masked decoding of multimodal protein language models, carrying a probability-weighted Top-k expectation embedding of uncommitted predictions forward as a soft anchor instead of resetting unresolved sites to an identical [MASK] embedding. HEME replaces inference-time intermediate reasoning in multimodal embedding models with a hindsight-distilled student: a teacher trained with access to the paired candidate (via a hindsight attention mask, mismatched-candidate conditioning, and query-token alignment) is frozen and its representation and similarity distribution are distilled into a student that encodes queries and candidates independently. Replaces security-guided quantization configuration selection and iterative gradient-based backdoor mitigation with a training-free repair: it measures per-module operator discrepancies between full-precision and quantized versions on identical states from the quantized trajectory, extracts dominant discrepancy directions on benign calibration data, and restores full-precision computation along those directions via a closed-form factorized residual adapter.

SPILLWAY: Separating Target Admission from Sanitization to Defend Tool-Using Agents against Prompt Injection

SPILLWAY replaces per-task LLM-based planning or routing for security with a deterministic admission check that validates tool-call targets against typed fields from read-only tools, plus a rule-based sanitizer that strips instruction-like regions before the model sees them. It costs implementation complexity: defining typed tool schemas, fixed delegation rules, sanitizer patterns, and an optional local judge, but adds almost no model-call overhead or latency. It can fail if attacks evade the fixed sanitizer rules, if delegation rules are misconfigured, or if legitimate targets are refused and the local judge errs, and it only defends against target-redirection, not other attack classes like data exfiltration through allowed targets.

TrustMI: Causally controlling how assistants trust their users

The method replaces fine-tuning or prompt-level instructions for controlling how much an assistant trusts its user, using steering matrices learned from 2,000 contrastive conversation pairs applied to frozen model activations. TileQuant replaces uniform-weight PTQ and column-wise mixed-precision retention with precision assignment at hardware-aligned 2D tiles, keeping only the highest-sensitivity tiles at 16-bit and quantizing the rest to 8-bit using offline calibration and a custom kernel. TACT-KV: Tri-Axis Cosine Transform for Compressing Volumetric KV Caches in Medical VLMs

TACT-KV replaces standard full-precision or token/feature-statistics-based KV cache compression with a calibration-free separable 3D discrete cosine transform applied to the KV cache, followed by reverse-water-filling bit allocation across frequency bins and fixed-codebook scalar quantization. It costs an additional transform/inverse-transform step on KV states per layer (modest compute and implementation complexity) and introduces quantization distortion that is only bounded by spectral concentration of the cache; at aggressive 1-bit budgets some prediction flips still occur. It can fail when KV energy is not spatially concentrated along anatomical axes, when workloads lack 3D spatial structure, or when the method is applied to models or tasks whose accuracy is sensitive to low-bit frequency truncation, since gains were validated mainly on 3D medical imaging and video tasks.

SPILLWAY: Separating Target Admission from Sanitization to Defend Tool-Using Agents against Prompt Injection

safety and guardrails · test · 3 of 4 implementations are independent

SPILLWAY replaces per-task LLM-based planning or routing for security with a deterministic admission check that validates tool-call targets against typed fields from read-only tools, plus a rule-based sanitizer that strips instruction-like regions before the model sees them. It costs implementation complexity: defining typed tool schemas, fixed delegation rules, sanitizer patterns, and an optional local judge, but adds almost no model-call overhead or latency. It can fail if attacks evade the fixed sanitizer rules, if delegation rules are misconfigured, or if legitimate targets are refused and the local judge errs, and it only defends against target-redirection, not other attack classes like data exfiltration through allowed targets.

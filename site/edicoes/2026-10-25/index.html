The KV-Surgeon: Compensation-Aware Offline KV-Cache Compaction

Replaces per-entry independent scoring for KV-cache eviction (e.g., attention matching) with a calibration-data-driven quadratic surrogate that jointly selects removals and compensates remaining entries, accounting for softmax renormalization. Cost is a one-time offline compaction pass with calibration data per fixed context, plus the memory of retaining a small calibration set; the compacted cache then reduces per-query memory and compute on repeated queries. It can fail when the queried context is not fixed and reused (no amortization of the offline cost), when calibration data is unrepresentative of production queries, or when compaction ratios are pushed beyond the validated operating points.

Signals and Queries: Token-Efficient Agentic Context Discovery

S&Q replaces per-turn LLM-based relevance evaluation of every behavioral policy with an offline-trained, per-policy logistic classifier over embeddings that filters candidates before any LLM call. The cost is an offline generation step (activating examples and hard negatives per policy), classifier training and maintenance per policy, and a small risk of false negatives that downstream stages never see. It can fail when user behavior drifts from the offline training examples, when new policies lack sufficient generated examples, or when embedding quality is poor for the domain, since a wrongly discarded policy is silently excluded from that turn.

PAUSE: Search-Free Steering of Coding Agents Before Their First Source-Code Edit

PAUSE replaces periodic trajectory reviews, learned monitors, and search-over-checkpoints steering with one intervention: the agent's first source-code edit is intercepted, a separate Planner model writes a repair plan from the pre-edit transcript, and the same agent resumes with its context and workspace intact. The cost is one extra Planner call per run (a strong frontier model such as GPT-5.6 Sol in the reported results), plus engineering to hook the edit tool in the agent harness; Executor compute is unchanged and offline replay saves 33-41% of Executor tokens versus restarting. It can fail when the Planner is weaker than the Executor's own reasoning, when the task's decisive error occurs after the first edit and is never revisited, or when the harness cannot expose a clean pre-edit interception point.

Corrected Block Sparse Spectral Optimization: Exact Models, Finite Identification, and Local Dynamics

Replaces dense PCA and the ambiguous standard block generalized-power sparse-PCA formulation with a primal-derived soft-threshold objective (A-SQ), a safeguarded Riemannian ascent with proven convergence, finite support identification, and post-identification refitting via power iteration. Cost is modest: Stiefel updates and thresholding on covariance-scale data run on a single GPU or CPU, with added implementation complexity for tie-breaking, zero-response columns, and mask-before-refit conventions. It can fail when the strict threshold-margin assumption does not hold, delaying or preventing support identification, and the quality gains are dataset-specific additive AMI improvements rather than guaranteed uplifts on arbitrary workloads.

Learning Functional Subspaces for Neural Network Compression

LSP replaces closed-form low-rank truncation criteria (activation energy, layer-wise reconstruction, quadratic loss approximations) with orthogonal projectors learned jointly against a global KL or training-loss objective, then merged into standard low-rank factors that also permit a shared narrow KV latent. The cost is an additional optimization pass over the projectors (weights stay frozen, so it fits one 24 GB GPU for models up to roughly 7B with careful handling), plus rank-allocation overhead and the engineering of tied-layer factor sharing, which is not yet an off-the-shelf library feature. It can fail when the KL-to-dense objective does not preserve task-specific behavior, when downstream kernels do not exploit the low-rank factors or shared latent (eliminating the speedup), and at extreme compression where even learned subspaces degrade.

Latent Projection for Latent Planning

The method replaces the raw l2 distance between predicted and goal latents with an l2 distance restricted to the k-dimensional subspace that the learned state dynamics propagate with least uncertainty, derived from a normal-matrix transition model fit under SIGReg regularization. The cost is fitting a single constrained matrix A post hoc; the encoder, predictor, rollout, and planner remain unchanged, adding negligible compute. The approach can fail if the SIGReg and Gauss-Markov assumptions do not hold for the reader's environment, if the latent dynamics are not well-approximated by a normal linear map, and the reported gains are demonstrated only on 2D navigation tasks, so transfer to other domains is unvalidated.

Feedback That Backfires in Games: Do LLM Players Repeat the Move They Just Watched Fail?

Replaces the common harness pattern of appending the failed action and error message verbatim into the transcript before retrying; use a failure description that omits the move string, or at minimum decoder-level bans on exact repeats. Improving the Expressive Power of Hybrid Sequence Models via Multi-Hop Retrieval

MuRA replaces conventional hybrid blocks (full-attention layers plus fixed-state efficient layers) by letting efficient layers perform m sequential retrieval hops from a shared KV cache, which provably enables m-function composition where existing blocks require capacity scaling as Omega(sqrt(n)) even for two hops. The cost is architectural: it is a new block design that requires training from scratch or fine-tuning a custom implementation, with added implementation complexity in the retrieval mechanism, though it preserves asymptotic compute and memory efficiency. It can fail in practice because the evidence is a theoretical expressivity hierarchy plus synthetic composition tasks; there is no demonstration on pretrained models, real downstream benchmarks, or pretrained-checkpoint compatibility, so gains may not transfer to production workloads.

MOSAIC: Multi-Objective Search for Allocating Inference Cache Across LLM Decoder Layers

MOSAIC replaces uniform per-layer KV-cache budgets (as used by SnapKV, H2O, AdaKV, L2Norm-style eviction) with a per-layer budget allocation found by one multi-objective search whose best allocation transfers across target budgets, optionally refined by a budget-constrained search. The cost is a one-time offline search per model and eviction method (reported as cheaper than EvolKV, but still multi-evaluation GPU work on a single 24 GB card for 7-8B models), plus serving-side plumbing to track and enforce per-layer budgets, with no runtime quality loss claimed at matched budgets. It can fail if the searched allocation does not transfer to models, tasks, context lengths, or eviction methods outside the validated Llama-3-8B / Mistral-7B and RULER/LongBench settings, or if the serving stack cannot apply heterogeneous per-layer budgets without kernel or scheduler changes.

SGAV-MP replaces uniform post-training quantization, pruning, or distillation pipelines that select layer precisions by Dice and size alone, by scoring quantization actions on a benefit-risk basis and accepting them only after full-model reliability validation on a calibration set. StreamAhead: Real-Time Streaming Video Question Answering via Adaptive Precomputation

StreamAhead replaces the standard practice of building full KV caches for every incoming video segment with a tiered scheme that keeps segments at cheap representation levels (visual features) and materializes KV caches only for query-retrieved segments. The method replaces additional cross-entropy pre-training of a limit-order-book generator with a short adversarial post-training stage: a WGAN critic evaluates free-running rollouts through the real matching engine and evolution strategies update rank-4 LoRA perturbations under a KL trust region. LOOP: Recovery-Aligned Iterative Layer Pruning via On-Policy Distillation

Replaces one-shot layer pruning followed by a single recovery phase with an iterative loop that removes one layer at a time, runs short on-policy distillation after each removal, and reuses recovery signals to select subsequent layers. Costs repeated distillation cycles with on-policy trajectory generation (teacher rollouts at every shot), which raises compute and wall-clock budget well beyond a one-shot prune, though it preserves a dense architecture that runs on standard hardware after pruning. Can fail if the per-shot recovery budget is insufficient to make the pruning signal informative, if on-policy distillation is unstable for the target model, or if the accuracy gains over cheaper one-shot baselines do not justify the added training cost on a limited budget.

How Much Does One Wrong Answer Cost? Error Propagation in Constraint Pruning with Noisy LLM Oracles

The method does not replace constraint pruning itself; it replaces the assumption that a correct oracle makes query order irrelevant, prescribing query orders (notably pivot orders for entity resolution) that bound how far one wrong LLM answer propagates. It costs nothing in extra queries or infrastructure, only deliberate ordering of the same yes/no questions, with pivot ordering being simple to implement. It can fail when error independence or small-epsilon assumptions break down (correlated oracle errors, systematic biases toward certain record pairs), since the guarantees are first-order in epsilon and the common most-similar-first ordering is provably the worst in one dimension.

Robust Latent Variable Graphical Models: Exact Recovery and Fundamental Limits

The method replaces the sample covariance in sparse-plus-low-rank precision matrix estimation with a centered Gaussian measure-transformed covariance, penalizing the low-rank component via a nuclear norm of a congruence transform. It costs a convex optimization solved by a linearized ADMM with closed-form updates, with statistical guarantees requiring N greater than roughly p/nu_min^2 samples for inertia recovery and restricted invertibility plus irrepresentability conditions on the Fisher information. Signed-graph and inertia recovery can fail when these structural conditions are violated, when the low-rank eigenvalues are too small relative to sample size, or under Huber contamination beyond the quantified bias bound, though the bound vanishes for remote outliers.

The method replaces end-to-end relation extraction with a decomposed pipeline: candidate concept pairs are enumerated first, then a TF-IDF Linear SVM or weighted RoBERTa classifier labels them as RESULTS_IN or CONTRIBUTES_TO. UserSWE replaces single-turn issue-report benchmarks with multi-turn coding tasks in which a persona-driven simulated user reveals information progressively and execution-grounded tests gate verdicts after every turn. Adopting it costs the construction or reuse of its task pipeline plus API or compute spend for running agents, the simulated user, and the dual-family verdict agents across up to eight turns per task. It can fail to transfer to a specific production setting because the 72 tasks and 42 repositories may not match the reader's codebase, and simulated-user behavior calibrated on past sessions may diverge from real user interactions.

ToM2Vec: Continuous Theory-of-Mind Tokens for Multi-Agent Coordination

ToM2Vec replaces explicit text-based reasoning about partner states with a fixed budget of continuous latent tokens trained to abstract a partner's thoughts. It costs the complexity of a specialized training phase supervised by partner thoughts and requires managing a latent conditioning mechanism that is less inspectable than text. A failure mode is that performance degrades if this latent reasoning is forced into text, and the abstract nature of the tokens could obscure errors in the agent's model of its partners.

Agent Behavior Maps: Locating Agents by What They Would Do, Without Running Them

The method replaces direct environment rollouts for comparing and predicting LLM agent behavior: instead of running each agent-harness combination in the environment, it cross-scores centered action log-likelihoods on shared reference trajectories to build a behavioral coordinate map. The cost is maintaining a set of reference trajectories, running one inference pass per candidate model over them, and accepting that trajectory-KL correspondence holds only under the paper's explicit assumptions, with the harness-composition extension showing accuracy varying across components and environments. It can fail when reference trajectories are unrepresentative of the deployment task distribution, when scoring diverges from actual rollout behavior for out-of-family models or novel harnesses, or when rank-order agreement with KL does not translate into accurate absolute performance prediction.

HGM-Dual: Lineage-Aware Guided Agent Harness Optimization for Long-Horizon Planning

HGM-Dual replaces unstructured agent archives and purely open-ended self-modification with lineage-aware evolution context plus dual-path child generation that targets likely constraint-violating harness components. It costs extra bookkeeping of ancestor edits, failure attribution, and multiple child evaluations per parent, so implementation complexity is nontrivial even though the base LLM can remain frozen or API-based. It can fail if constraint diagnostics are wrong, lineage records attribute improvements incorrectly, or planning tasks do not show stable constraint-violation patterns for specialized edits to exploit.

SWE-DIVE: Multi-Turn Coding Agent Evaluation with Dynamic User Simulation

SWE-DIVE replaces static, one-shot GitHub-issue benchmarks (e.g., SWE-bench) with dynamic, multi-turn user simulation to evaluate coding agents. It introduces complexity by requiring a user simulator, conversation validator, and orchestration environment (Harbor), which increases setup overhead and evaluation cost compared to single-turn benchmarks. Potential failure modes include unrealistic user behavior simulation, validator misalignment with true task requirements, and high infrastructure demands for continuous orchestration that may exceed constrained budgets.

The KV-Surgeon: Compensation-Aware Offline KV-Cache Compaction

KV cache · test · 2 of 2 implementations are independent

Replaces per-entry independent scoring for KV-cache eviction (e.g., attention matching) with a calibration-data-driven quadratic surrogate that jointly selects removals and compensates remaining entries, accounting for softmax renormalization. Cost is a one-time offline compaction pass with calibration data per fixed context, plus the memory of retaining a small calibration set; the compacted cache then reduces per-query memory and compute on repeated queries. It can fail when the queried context is not fixed and reused (no amortization of the offline cost), when calibration data is unrepresentative of production queries, or when compaction ratios are pushed beyond the validated operating points.

AngelSpec: Towards Real-World High Performance Inference with Speculative Decoding

Replaces one universal speculative drafter with two specialized drafters, MTP for chat and block diffusion for code and mathematics, plus adaptive batched verification. It requires training both drafters for Hy3 target models and a custom server with a profiled verification-cost model. Benefits depend on trained drafters and control of the serving loop, which excludes third-party APIs and unsupported open models.
